# MovieMaker

静止画（カバー）と音楽ファイルから、YouTube向けの動画を生成するWindows用WPFアプリです。
画像の向きから通常動画とShortsを自動判定します。横向き・正方形画像は通常動画、縦向き画像はShortsです。
通常動画では曲名文字入れの有無を選べます。文字入れありは各音声ファイル名（拡張子を除く）をJSON指定領域に配置し、文字入れなしは共通画像1枚を全トラックに使用します。

## 主な機能
- 音楽ファイル・音楽フォルダと画像を順不同で1件ずつドラッグ&ドロップで指定（音声はトラック末尾へ追加。フォルダはサブフォルダも検索）
- 画像のサムネイルと音声トラック一覧を表示。画像の置換・取り外し、音声の追加・削除・並べ替えで自動判定を更新
- 通常動画の文字入れありでは大きなJSON編集ウィンドウで曲名の位置・書字方向・フォント・色を指定。文字入れの選択と設定JSONは次回起動後も保持
- 音声トラックを左の一覧で選択し、上へ／下へ／先頭へ／末尾へ移動。ドラッグ&ドロップでの並べ替えと個別削除にも対応
- 音声トラックの表示順と再生時間から、YouTubeチャプター形式（HH:MM:SS 曲順.曲名）をUTF-8テキストへ書き出し
- 入力音声と生成後の音声をIntegrated LUFS / True Peak / LRAで解析。トラック一覧では入力が-15 LUFS未満または-12 LUFS超、True Peakが-1.0 dBTP超の場合に確認を促す
- 通常動画は文字入れの有無によらず各楽曲を個別にノーマライズ（初期値 -14 LUFS / -1 dBTP）。標準目標値は設定画面で指定し、必要な音声トラックだけ個別に上書き
- タイトルバーの「LUFS」から既存動画を複数ドロップして、音量を一覧解析
- 入力音声は MP3 / WAV / AAC / M4A（AAC・Apple Lossless）/ FLAC に対応
- 画像の実寸で縦横を自動判定。9:16 / 16:9 以外と正方形は比率を維持して黒帯を付け、警告を表示
- タイトルは画像ファイル名から自動補完（必要に応じて手動編集）
- 出力先とアーカイブ先を別指定
- ffmpegで高音質エンコード（AAC 320kbps / 48kHz）
- GPU対応エンコーダが利用可能なら自動で使用（NVENC/QSV/AMF）
- Shorts は縦 1080x1920 / 30fps / AAC 128kbps / 32kHz で出力
- 仮動画モードでは横固定の仮画像を自動生成し、画質を軽くしつつ音声は高音質 / 低音質を切替可能

## 動作環境
- Windows 10/11
- .NET 8 SDK 以上
- ffmpeg（同梱またはPATHに登録）

## セットアップ
1. .NET 8 SDK をインストール
2. ffmpeg をインストールし PATH を通す
- `ffmpeg` が `Get-Command` で見える状態にする

## 起動
```powershell
dotnet run --project .\MovieMaker.csproj
```

## 配布（ZIP）
自己完結の単一ファイルで発行し、`publish` フォルダをZIPにして配布します。
ffmpegは別途インストールし、`PATH` が通っている必要があります。

```powershell
dotnet publish .\MovieMaker.csproj -c Release -r win-x64 --self-contained true `
  /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true `
  /p:PublishTrimmed=false
```

出力先:
```
bin\Release\net8.0-windows\win-x64\publish\
```

## デプロイ
デプロイは依頼があった場合に実施します。配置先は `C:\app\MovieMaker\MovieMaker.exe` です。「デプロイ」と依頼された場合は、この場所へ配置します。

Release版を発行して、実行ファイルを配置先へ上書きコピーします。

```powershell
dotnet publish .\MovieMaker.csproj -c Release -r win-x64 --self-contained true `
  /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true `
  /p:PublishTrimmed=false

Copy-Item -LiteralPath .\bin\Release\net8.0-windows\win-x64\publish\MovieMaker.exe `
  -Destination C:\app\MovieMaker\MovieMaker.exe -Force
```

## 使い方
1. 設定画面で「出力先」と「アーカイブ」を設定
2. タイトルを確認（画像ファイル名から自動補完されます）
3. 画像と音声を順不同でドロップ。縦画像はShorts、横向き・正方形画像は通常動画に自動判定されます。仮動画だけは「仮動画を作る」を明示選択します
4. 通常動画では「曲名を文字入れする」を選択できます。オンの場合は「文字入れJSONを編集」から配置設定を保存してください。Shortsは文字入れなしで、画像1枚と上限以内の音声1本が必要です
5. 左の一覧で音声トラックを選択し、「上へ／下へ／先頭へ／末尾へ」で並べ替える。一覧内では Alt+↑／Alt+↓／Alt+Home／Alt+End も使用できます。ドラッグ&ドロップも利用できます
6. 入力状態がエンコード可能になったことを確認し、「エンコード開始」を押す

「チャプターを書き出し」から、音声トラックの並びと再生時間を使った `00:00:00 1.曲名` 形式のテキストを保存できます。時間は音声トラックごとの長さを順に累積します。

画像は右ペインで追加・確認・取り外しできます。縮小表示は入力画像の確認用で、曲名文字入れ後の完成プレビューではありません。音声一覧と画像確認は通常動画・仮動画・Shortsで同じ位置に表示します。

出力先とアーカイブ先のパス確認・編集、フォルダーを開く操作は「設定」にまとめています。主画面下部には「出力フォルダーを開く」も残しているため、生成後すぐに結果を確認できます。

通常モードでは、各楽曲を個別に測定してからノーマライズし、表示順に連結します。標準目標値は設定画面で指定でき、初期値は -14 LUFS / -1 dBTP です。音声トラックの「目標：共通／個別」から編集画面を開くと、そのトラックだけ目標を上書きできます。保存で反映し、キャンセルでは変更しません。設定できる範囲は -70〜-5 LUFS、-8〜0 dBTP です。True PeakはAAC変換時に目標より1 dB低く処理し、変換後のピーク上昇に備えます。

音声トラック一覧のLUFS / True Peak表示はノーマライズ前の入力値です。-15 LUFS未満と-12 LUFS超、True Peakの-1.0 dBTP超は、音源を事前に仕上げるかツールに任せるかを確認するための注意表示です。通常動画では各トラックを目標値へノーマライズしてから出力します。仮動画とShortsでは曲別ノーマライズを行いません。エンコード後は生成ファイルを再解析し、出力値をステータスに表示します。LRAは参考値として表示します。

既存動画の音量を確認する場合は、タイトルバーの「LUFS」を開き、MP4 / MOV / MKV / WebM などの動画をドロップします。動画ごとにIntegrated LUFS、True Peak、LRAを解析し、-16〜-12 LUFS以外または-1.0 dBTP超過を「要確認」と表示します。音声ストリームがない動画や解析に失敗した動画は「解析不可」と表示します。

表示の優先順位、情報の反復、警告、操作寸法と配置の基準は [UIポリシー](docs/ui-policy.md) を参照してください。

## 出力ルール
- 出力先
`出力先\{タイトル}_yyyyMMdd_HHmmss.mp4`
- アーカイブ
`アーカイブ\{タイトル}\` に元データをコピー
- 同名タイトルが存在する場合
`{タイトル}_yyyyMMdd` を付与し、さらに重複時は `_1` などを追加

## 制約
- 通常動画は横 1920x1080 / 30fps / AAC 320kbps / 48kHz 出力。画像が16:9以外なら警告し、比率を保って黒帯を付ける
- 通常動画は画像1枚と音声1本以上が必要。文字入れありの場合だけ有効なJSONが必要です。文字入れなしも同じ品質・曲別ノーマライズ・曲別overrideを適用します
- 文字入れのフォントにはWindowsへSource Han Sans JPをインストールし、JSONの `font.id` に `source-han-sans-jp-heavy` を指定
- 通常モードのノーマライズは音声トラックごとのLUFS測定を基準にするため、完成動画全体のIntegrated LUFSは目標値からわずかにずれる場合がある
- 縦画像は音声が0本でもShorts確定で音声待ちです。2本以上の音声、または1本の音声が設定上限を超えると入力エラーになり、原因を取り除くと解除されます
- 画像を登録する前は音声の本数と長さからShorts候補または通常動画候補を表示します。音声時間を取得できない場合は入力エラーとして表示します
- 横向き・正方形画像と音声の合計尺がShorts上限以下なら、通常動画として尺が短い警告を表示します
- 画像を再度ドロップすると背景画像を置き換え、音声ファイルまたは音声フォルダを再度ドロップすると既存トラックの末尾へ追加（フォルダはサブフォルダも検索）
- 複数音声は画面の表示順で連結し、同じパスの音声は重複追加しない
- M4A は DRM 保護されていない AAC / Apple Lossless（ALAC）音声を入力として扱い、出力音声は選択したモードの AAC 設定へ変換
- Shortsの最大秒数は設定画面で1～180秒の整数から指定し、初期値は60秒です。音源が上限を超えた場合は入力エラーです。完成動画はコンテナと音声・映像の実終端が上限以内と確認できてから公開用ファイルにします
- 従来の短縮規則も残します。1分枠は `60 - 1分オフセット` 秒から60秒まで、3分枠は `180 - 3分オフセット` 秒以上を各しきい値に短縮し、末尾1秒をフェードアウトします。入力上限を超えた音源を旧規則で救済しません
- Shorts 短縮時は、フェードアウト後に発生した末尾の実質無音を自動で除去
- 1分オフセットは0～59秒、3分オフセットは0秒以上120秒未満です。既存設定が範囲外なら自動補正せず設定画面にエラーを表示し、修正するまで通常動画とShortsをエンコードできません。仮動画はShorts尺設定に依存しません
- 仮動画モードでは横 960x540, 24fps を使用し、音声は高音質 `AAC 256kbps / 44.1kHz` または低音質 `AAC 128kbps / 32kHz` を選択可能
- Shortsの出力ファイル名には `light-audio_` プレフィックスを付与
- 仮動画モードの出力ファイル名には `draft-preview_` プレフィックスを付与

## ログ
- `logs/` にffmpegのログを出力
- 設定画面でShortsの最大秒数と1分枠 / 3分枠のオフセット秒を変更可能
