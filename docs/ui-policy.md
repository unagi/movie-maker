# UIポリシー

この仕様は、主画面・設定・音量解析・各編集画面の表示と操作を判断する基準です。機能の変更とともに更新します。

## 目的

同じ文字・情報が強い調子で繰り返されることで、必要な違いを見分けにくくなる状態を避けます。情報量を減らす際も、対象・単位・状態・操作の意味を保ちます。

## 共通原則

| 項目 | 規則 |
| --- | --- |
| 反復 | 同じラベル・数値・説明・警告は原則繰り返しません。同義の評価語・警告文・バッジで強調を重ねません。 |
| 近接 | 同じ対象と目的の値を内容幅と一定の間隔でまとめます。画面幅に比例して数値同士を離しません。 |
| 優先順位 | 対象名を第一に、属性・測定値、局所操作を整理します。入力の測定値と処理目標を区別します。 |
| 配置の安定 | 通常の有効／無効・値編集だけで一覧の行高や後続項目を動かしません。使わない専用行も常設しません。詳細編集は明示的に開き、閉じた後は元の操作へ戻れるようにします。 |
| 状態 | 未設定・解析中は中立、判断の余地がある注意は控えめな警告、対応必須の失敗は明確に区別します。色だけで意味を伝えません。 |
| 文言 | 対象・事実・選べる対応を示します。「注意」だけで終えず、推奨範囲を絶対的な適否にしません。理由の詳細は必要時に確認できます。 |
| 操作 | 主操作・通常操作・欄内補助操作・アイコン操作を役割で分類し、同じ役割の寸法と視覚的な強さを揃えます。 |
| 余白 | 親が情報群の間隔、子が内部余白を持ちます。局所指定を積み重ねて高さを調整しません。 |
| 可読性 | 長い名前、最小画面幅、DPI拡大でも値と操作を欠けさせません。固定高さへ文字を押し込めません。キーボード操作とフォーカスの視認性を保ちます。 |

同じ情報の反復を許すのは、別対象の識別・別の判断・独立して読まれる文脈に必要な場合です。例えば、各音声の単位、編集画面内の対象名、入力値と生成結果の値は識別に必要です。単に目立たせる目的では繰り返しません。

特別な高さ・色・段追加が必要になったら、共通原則で扱えるか見直します。用途差で必要なものは役割と理由をここに記録します。モード変更による作業構成の変化と、同じ作業内の設定変更を区別します。

## 音声トラック

- 音声一覧を左の主領域、入力画像の縮小確認を右ペインに配置します。通常動画・仮動画・Shortsで一覧の位置と高さの使い方を揃え、一覧だけをスクロールします。
- 並べ替えは選択した1曲に対する共通ツールバーの「上へ／下へ／先頭へ／末尾へ」と、一覧内の Alt+↑／Alt+↓／Alt+Home／Alt+End を提供します。既存のドラッグ操作も維持します。移動後は対象の選択・表示・フォーカスを保ち、端・未選択・エンコード中は該当操作を無効にします。
- タイトルと出力モードは上部、開始操作と進捗は下部に配置します。右ペインのエンコード詳細は明示的に展開し、音声一覧の高さを奪わないようにします。
- パス確認・編集とフォルダーを開く操作は設定画面にまとめ、主画面には設定への導線と出力フォルダーを開く補助操作を残します。未設定の説明は主画面の状態表示で伝えます。

- ファイル名・素材属性に続き、入力のLUFS・True Peak・LRAを近接した一群で示します。下部へ同じ測定値を再掲しません。
- 個別目標は調整ONの通常複数トラックだけ一覧から編集画面を開き、共通／個別と目標値を選択します。保存で反映し、取消では変更しません。一覧に入力段を追加しません。
- 入力が -15 LUFS未満、-12 LUFS超、True Peakが -1 dBTP超の場合は、素材を事前に仕上げるかツールで調整するかを判断する注意です。LRAは参考値です。
- 警告は短い理由と必要時の説明で伝えます。同じ注意文を各行と一覧下部へ繰り返しません。正常な各数値に「OK」「適正」を付けません。
- 通常動画は単一トラックなら調整なし、2トラック以上なら各曲を目標値へ調整します。生成動画欄に動画単位のOFFチェックを示し、曲単位のON／OFFや常設グローバルOFFは設けません。新規・入力クリアでは動画単位OFFを引き継ぎません。
- 仮動画は横固定で高音質／軽量の選択が可能です。Shortsは音声1トラック・高音質固定です。いずれも音量調整なしです。この処理説明は一覧で一度示し、入力警告から調整を自動ONにしません。
- 解析中・解析失敗は同じ説明を指標ごとに繰り返さず、測定値群の状態として扱います。

## 操作と寸法

復元用設定は主画面の「復元設定を読み込む」「復元設定を保存」とJSONの単体ドロップから扱います。
読み込み済みの処理設定は「今回の設定」で編集し、「設定」は現在のPCの出力先・アーカイブ先を扱います。
現在の入力を置き換える場合と既存JSONを上書きする場合は確認します。復元だけではエンコードを開始しません。
既存アーカイブから作ったJSONの未確定値は、現在値を候補として示し、利用者が確認して今回の値へ確定します。
対象モードで使わない未確定値は保存したままにし、必要になるモードへ切り替えたときに確認します。
動画単位のOFFは今回の動画と保存復元にだけ適用します。旧保存からの復元では、Shortsの高音質化・単一通常動画の調整なしへの変更を表示します。

欄内の「チャプターを書き出し」「文字入れJSONを編集」「画像を外す」は補助操作です。大きな実行ボタンと同じ高さにしません。補助操作は約28〜32 DIP、主操作は44 DIP程度を基準に、文字とフォーカスが収まる最小寸法を使います。内側の余白が実際のテンプレートへ反映されることを確認します。

関連情報の間隔は4〜8 DIP、群の間隔は12〜16 DIPを目安にします。数値は画面の実寸検証で調整できる値であり、文字を切り詰める理由にはしません。

## 反復・特例の棚卸し

| 対象 | 判断 |
| --- | --- |
| 各トラックの単位・曲順 | 別対象を識別するため維持 |
| 入力測定と生成結果 | 別の判断と時点のため維持 |
| 既存動画の音量解析 | 独立した確認作業。入力素材の判断基準とは区別し、既存の -16〜-12 LUFS基準を維持 |
| 主画面と編集画面の対象名 | 編集対象を独立して確認するため維持 |
| モード変更による表示構成 | 作業に必要な項目が変わるため許容。設定の有効化だけによる一覧の段追加とは区別 |
| 同じ警告文・同義評価の重ねがけ | 削減対象 |
| 補助ボタンの局所的な大きさ | 同役割の基準へ整合 |
| 画像比率の注意 | 出力を妨げない注意として扱う |

## 受入確認

1. 画面幅を広げてもLUFS・True Peak・LRAの間隔が拡大しない。
2. 個別目標の編集前後で一覧の行高と後続項目の位置が変わらない。保存・取消・無効入力の扱いが明確である。
3. 注意の対象・理由・選べる対応が分かり、実際の出力モードと説明が一致する。
4. 補助ボタンが不要に欄の高さを増やさず、文字・操作・フォーカスが欠けない。
5. 同じ画面の数値・ラベル・警告を棚卸しし、必要な反復は上記の理由を説明できる。
6. 通常／仮動画／Shorts、空／単一／複数トラック、動画単位OFFと本数変更、解析中／成功／失敗、各警告、共通／個別目標、文字入れの有無を確認する。
7. 最小幅1120・通常幅1280、DPI100／150／200%、長いファイル名で確認する。

表示の変更は、エンコード処理・警告閾値・正規化目標の意味を変更しません。GUI未確認の条件は実施済みと扱わず、検証結果に残します。
